---
title: a13n Claw
description: A persistent Inbox and managed workers for A13n Service.
---

Claw coordinates incoming work through one persistent Main Thread. GitHub, Lark, and Main-mode scheduled work enter the Claw Inbox. Main opens the work it chooses and delegates longer assignments to Service's native asynchronous child Threads.

[Get started](./getting-started.md), then use [Console](./console.md) to inspect activity and follow native Thread and Run links.
