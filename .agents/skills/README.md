# Repository Skills

These skills support work in this standalone repository. They follow [AGENTS.md](../../AGENTS.md), [CONTRIBUTING.md](../../CONTRIBUTING.md), and [DEVELOPMENT.md](../../DEVELOPMENT.md); loading a skill does not grant permission to publish, merge, deploy, or change unrelated work.

| Skill                                                                 | Purpose                                                             |
| --------------------------------------------------------------------- | ------------------------------------------------------------------- |
| [Repository consistency audit](audit-repository-consistency/SKILL.md) | Review contract and implementation consistency with evidence.       |
| [Commit, push, and PR](commit-push-pr/SKILL.md)                       | Prepare authorized Git and GitHub handoffs.                         |
| [Specification writing](spec-writing/SKILL.md)                        | Maintain self-contained accepted contracts and their reading paths. |
| [UI/UX polish](uiux-polish/SKILL.md)                                  | Refine implemented frontend pages and interactions.                 |
| [Worktree to PR](worktree-pr/SKILL.md)                                | Isolate explicitly requested worktree tasks and deliver a PR.       |

The specification-writing skill includes references for [document structure](spec-writing/references/structure-and-template.md) and [domain modeling](spec-writing/references/domain-modeling-and-naming.md). Commands and links target this repository; no neighboring checkout is required. Skills are contributor tooling and are not included in Python release artifacts.
