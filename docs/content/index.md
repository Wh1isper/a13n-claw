---
title: a13n Claw
description: A persistent Inbox and managed workers for A13n Service.
---

Claw coordinates incoming work through one persistent Main Thread. GitHub, Lark, scheduled work, and worker reports enter its Inbox. Main opens the work it chooses and delegates longer assignments to independent worker Threads sharing one Project.

[Get started](./getting-started.md), then use [Console](./console.md) to inspect activity and follow native Thread and Run links.
